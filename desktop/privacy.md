# 绮录QQ聊天记录导出软件隐私条款

条款版本：2026-11-06.1

更新及生效日期：2026 年 11 月 6 日

## 一、适用范围与联系主体

本条款适用于「绮录QQ聊天记录导出软件」（简称「绮录」）的官方 Windows 桌面发行版。项目由 GitHub 维护者 qingzhi-star 维护，公开联系渠道为 https://github.com/qingzhi-star/QL-qq-chat-history-exporter/issues 。本项目与腾讯及 QQ 官方无关联，未获官方授权。

绮录用于在本人设备上浏览、解密、整理和导出本人依法有权处理的 QQ 本地记录。维护者不通过绮录接收、集中存储或远程处理你的聊天数据库、正文、媒体或数据库口令。你主动向第三方发送导出文件、上传反馈或使用第三方云盘的行为，由你另行决定，并受相应服务的条款约束。

## 二、同意前后的处理边界

每次启动桌面软件，首先显示本条款。你可以在本机阅读全文，或主动点击链接通过系统浏览器访问 GitHub Pages 在线版本。打开软件本身不要求联网阅读。

点击「同意并进入」之前，绮录不启动聊天读取内核，不发现 QQ 账号、不访问 QQ 数据库、不读取 QQ 进程内存、不加载网络头像。窗口显示所必需的程序资源、操作系统运行信息及 Electron 自身技术缓存不属于聊天数据读取。

你可以点击「拒绝并退出」，或直接关闭窗口；软件会退出，不开始账号或聊天数据处理。接受仅对本次运行有效，不将沉默、继续停留或关闭提示视为同意。下次启动仍需重新选择。

同意后，软件可能自动准备上次使用或唯一的本机账号。你可以选择其他账号、会话、日期、消息和导出格式，并随时退出软件停止后续处理。退出不自动删除此前自行保存的导出文件或本机缓存。

## 三、访问的信息、用途与方式

- 本机账号与目录信息：QQ 号、本机 QQ 数据位置、文件存在状态、大小和修改时间，用于发现账号、检测新记录、读取一致副本和切换账号。可能读取本机安装路径配置，不读取 QQ 登录密码。
- 联系人与群资料：昵称、备注、群名片、群名称、QQ 号及群号等，用于显示发言者与会话。为匹配显示名称，可能读取所选账号本地联系人及群资料库。
- 聊天记录：发送者标识、消息编号、时间、正文、引用、转发摘要、撤回及消息类型等，用于浏览、排序、搜索、选择、导出、增量备份或归档。建立所选账号的会话与定位索引可能读取该账号全部本地消息的必要字段；导出内容由你的选择决定。
- 本地媒体与附件：已缓存的图片、表情、音频、视频、文件及名称、大小、路径等，用于预览、复制、生成缩略图和导出。软件不能恢复从未下载或已经删除的资源；原始语音不自动转写。
- 数据库口令：用于解密和校验你选择的本机 QQ 数据库；它不同于 QQ 登录密码。已有有效口令时可离线使用。需要获取口令时，软件只读访问本机 QQ 进程中的候选数据并用所选数据库认证，不注入程序、不写入 QQ 进程、不改 QQ 安装文件。候选数据仅在本机内存中短暂处理，不作为聊天内容、报告或日志输出。
- 使用设置与任务信息：上次账号、输出位置、导出格式、窗口设置、消息密度、缓存上限，以及你主动保存的搜索历史、导出队列、检查点、增量清单或计划文件，用于恢复设置及执行对应操作。

绮录对 QQ 原始数据库与 WAL 只读，通过临时副本解密和解析，不将解密内容回写 QQ。搜索索引默认只存在本机内存；保存搜索关键词历史是独立可选项。

## 四、敏感个人信息与其他参与者信息

聊天中可能包含通信内容、身份资料、金融账户、健康情况、位置、面部图片及不满十四周岁未成年人的信息等敏感个人信息。绮录不会为了建立用户画像而专门识别、标注或推断这些属性，但读取与导出记录仍可能实际处理这些内容。

处理这些内容的必要性限于你请求的本机浏览、检索和备份。泄露导出文件、明文缓存或数据库口令，可能导致他人通信隐私、身份、财产或人身权益受损。请缩小账号、会话、日期及消息范围，并保护输出目录。

启动确认中对所选记录可能包含敏感个人信息设置单独的确认项。你应仅在依法具备相应处理依据时操作；在法律要求单独同意、书面同意或监护人同意的情形下，应先满足相应条件。你点击同意不能代替聊天其他参与者的授权，也不使无权处理、公开或传播他人信息的行为合法。

不满十四周岁的使用者应在监护人知情、同意并指导下使用。不得利用本软件绕过设备权限、取得他人账号数据、跟踪、骚扰、交易个人信息或实施其他违法行为。

## 五、联网行为与第三方

核心解密、解析、搜索及普通导出在本机执行，默认不联网下载缺失媒体；未集成广告、用户行为统计或聊天上传服务，也不自动向维护者发送崩溃报告或诊断数据。

「允许联网加载 QQ 公开头像」为独立可选项，默认不勾选，拒绝不会阻止浏览及导出。勾选后，为显示用户或群头像，软件会向腾讯运营的 q1.qlogo.cn 或 p.qlogo.cn 发送包含相关 QQ 号或群号的 HTTPS 请求。服务方还会按网络通信接收到来源 IP、请求时间、请求头等信息，并依其规则处理。聊天正文、数据库口令和附件不随头像请求发送。未允许时不发出该类请求，显示占位头像；本次运行的选择可在下次启动时改变。

隐私条款在线地址由 GitHub Pages 托管。仅在你主动点击在线阅读链接后，系统浏览器访问 GitHub；GitHub 可能处理访问 IP、浏览器信息及访问日志。浏览器自身或 GitHub 的账户、Cookie 和隐私规则由相应服务负责。在线页面不嵌入统计脚本、广告、外部字体或个人信息收集表单，打开链接不会附加你的 QQ 号、聊天信息或口令。

点击图片或附件会调用系统默认查看器。对应程序可能读取所打开的副本；其联网和隐私行为受其自身设置与条款约束。请自行选择可信的查看器。

本软件不主动将聊天数据跨境传输，也不向维护者或其他主体出售、共享、委托远程处理聊天数据。你主动访问境外网站或将文件保存到同步盘可能涉及独立的第三方处理，不能以「本机导出」推断这些后续行为不会联网。

## 六、本地存储与保存期限

- 数据库口令通过 Windows DPAPI 保护后保存在当前 Windows 用户的本机配置目录，默认 `%LOCALAPPDATA%/QQExport/keys.json`。保存至你主动清除或不再保留该目录；绑定当前用户和设备，不应当作可任意迁移的密钥备份。
- 解密工作副本保存在本机应用工作目录，正常关闭相关数据源或退出时尝试清理。异常断电、崩溃、文件被占用可能留下副本；以后使用相关功能时尝试清理过期工作目录。不承诺系统级安全擦除或所有异常均无残留。
- 缩略图和供系统查看器打开的图片副本保存在应用缓存目录，按容量规则清理，也可通过「更多功能 → 清理图片缓存」处理；占用中的文件可能暂时无法删除。
- 设置、可选历史、队列和检查点保存在本机配置目录或你选择的位置，保留到你清除或删除对应文件。Electron 另有窗口配置和运行缓存，位于当前 Windows 用户应用数据目录。
- 导出文件、普通归档、增量快照及资料库可能包含明文记录和附件。选择归档密码时，该归档采用加密存储，但你随后导出或导入明文资料库的副本并不因此继续受归档密码保护。归档密码不保存，遗忘后无法恢复。
- 导出内容和归档保存在你指定的目录，资料库保存在本机应用目录，均由你决定保留期限；卸载软件不会自动删除 QQ 原始数据、你的导出文件及原有账号缓存。

## 七、查看、更正、删除与撤回

你可以自行查看导出文件、切换账号、缩小筛选范围、清除搜索索引及历史、清理图片缓存，或在「更多功能」清空本机资料库。更正原始消息应通过 QQ 或重新生成导出文件完成；绮录不修改 QQ 原库。

退出软件即可停止本次后续处理；下次启动拒绝条款则不会开始新的数据读取。已生成文件不会随撤回而自动消失，需要自行删除。退出后可删除本机 QQExport 应用目录以移除绮录保存的口令、设置、工作副本、资料库及缓存；请先确认需要保留的资料已备份，勿删除 QQ 自己的数据目录。开发者命令行还提供 `key clear` 清除本机口令。

如需反映隐私问题、提出删除或更正请求，可通过项目 Issues 联系维护者。GitHub Issues 为公开页面，请勿填写完整账号、身份证、聊天正文、原始数据库、口令、个人路径或未脱敏日志。维护者没有接收到的本机数据无法由维护者远程替你删除；对于你主动向维护者提供的信息，可说明请求范围，并避免再次公开敏感材料。

## 八、安全措施与风险

采取只读源文件、临时工作副本、受限本机进程通信、渲染隔离、受限文件选择器、DPAPI 口令保护及可校验归档等措施降低风险。这些措施不等于绝对安全，也不能防止设备已被入侵、同一 Windows 用户下的恶意程序、云同步误配置、截图传播或你主动分享文件造成的泄露。

不要在共享或不可信设备上处理敏感记录，不要将导出目录放入不必要的公共共享或同步位置。发现异常访问、密钥泄露或隐私问题时，立即停止使用，保护原始数据、清理不必要副本并通过公开联系渠道报告可披露的最少信息。

本条款不限制依法享有的个人信息权利，不以开源许可或免责声明免除法定责任，也不将「点击同意」视为对所有未来用途或其他主体的无限授权。

## 九、条款更新

隐私条款随软件版本维护。处理目的、信息种类、联网对象或存储方式等发生实质变化时，应更新条款版本并在新的软件启动确认中告知，不能以旧同意代替对实质变化的重新选择。

软件内附带的本机全文与该发行版条款对应；在线页面可能更新。在线链接不可访问时仍可阅读发行版内附全文。如二者版本不同，以本次软件展示的条款版本为本次处理说明，并可退出后核对更新。

请在理解上述处理方式、可选联网行为、敏感信息风险和离线能力边界后作出选择。
