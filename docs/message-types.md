# P2 消息类型与降级

| 类型 | 预览 / TXT | HTML / PDF | 边界 |
|---|---|---|---|
| 文本、Markdown、表情 | 本地文本投影 | 转义文本、本地表情 | 不执行卡片脚本，不下载远程图片 |
| 图片 | 按需缩略图 / 图片占位及缺失说明 | 原图内嵌，缺失说明 | 原图仅按需读取 |
| 回复、撤回 | 引用与撤回标记 | 引用块与撤回标记 | 引用递归最多 8 层 |
| 老式转发 | 本地 XML 正文展开 | 可折叠、默认展开 | 最多 1Mi 字符；超限或解析失败明确提示 |
| NT 合并转发 | 存在本地 messages 文本列表时展开 | 同左 | 常见只有服务器卡片引用时保留卡片，标记未展开，不联网取回 |
| 语音 | 时长（支持小数秒） | HTML 原始音频下载，PDF 显示时长 | 不转码、不转写、不保证 SILK 可被浏览器播放 |
| 文件、视频 | 类型、名称、本机缺失状态 | HTML 独立副本链接 / PDF 文本 | 外部打开前另存副本，防止编辑源附件 |
| 卡片 | 本地 title/desc/prompt/summary | 转义文本 | 无标题回退 app 名；不加载远程卡片 |
| 红包、通话 | 类型、可用标题或通话秒数 | 同左 | 不推断本机没有的金额、状态或内容 |
| 未知 | 未解析标记 | 未解析字段及有限原始摘要 | 不丢弃整个会话 |

所有消息均携带原始消息时间。虚拟列表单条预览超过 8000 字时明确省略，复制与
导出保留完整已解析内容。TXT 的非文本占位现在增加文件名、时长和缺失说明，因此
与早期版本的纯占位字符串存在预期差异；增量格式版本保持一致性校验，不回写旧消息。

矩阵是合成协议样本的自动回归覆盖，不代表所有 QQ 版本的所有私有变体均已实机验证。
