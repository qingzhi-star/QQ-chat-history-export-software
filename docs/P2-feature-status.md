# P2 功能验收表

“实现”表示代码与合成回归已完成，不等同所有 QQ 变体/系统真机已通过。
P1+ T01–T10、P2 T01–T11 的逐任务证据见 [实施记录](P2-progress.md)。

| 需求 | 状态 | 实现 / 边界 |
|---|---|---|
| F01 会话搜索 | 实现 | 内存索引，跳转高亮 |
| F02 全库搜索 | 实现 | 跨会话结果，首次后台建索引 |
| F03 组合筛选 | 实现 | 发送者、类型、日期、会话 |
| F04 搜索历史 | 实现 | 默认关闭，显式开启，可清除 |
| F05 正则/精确 | 实现 | 默认包含，regex 实际超时 |
| F06 结果导出 | 实现 | 全部匹配结果 TXT/HTML |
| F07 上下文 | 实现 | 跳转定位并保留邻近消息 |
| F08 多会话 | 实现 | 主界面 Ctrl 与批量选择窗口 |
| F09 全部导出 | 实现 | 明确确认，空会话跳过 |
| F10 队列 UI | 实现 | 状态、数量、取消 |
| F11 失败隔离 | 实现 | 单任务失败，重试失败项 |
| F12 导出清单 | 实现 | 可选清单与文件哈希 |
| F13 重启恢复 | 实现 | 可选检查点，账号及已完成文件校验 |
| F14 计划导出 | 可选预览 | 生成默认禁用 XML / JSON，单次运行；系统导入触发尚未真机验收 |
| F15 已有备份识别 | 实现 | manifest、尾游标、旧文件验证 |
| F16 仅追加 | 实现 | TXT/HTML 追加，PDF 重生 |
| F17 一致性 | 实现 | 数量/首尾语义/文件哈希，冲突停止；不审计历史中部修改 |
| F18 修复 | 实现 | 显式全量重建，保留旧清单，不静默修补 |
| F19 旧版本迁移 | 实现 | 无清单不推断游标，明确选择全量重建 |
| F20 归档 | 实现 | 版本化 ZIP / JSONL / HTML / 媒体 |
| F21 校验和 | 实现 | 打开全部校验、ZipSlip 等结构检查 |
| F22 离线 | 实现 | 无 QQ 浏览、搜索、选择及导出 |
| F23 加密 | 实现 | scrypt + AES-256-GCM，密码不保存 |
| F24 合并 | 实现 | 显式明文资料库，账号隔离、去重、冲突事务回滚 |
| F25 缺失清单 | 实现 | 当前会话、ID、类型、时间及定位，分页 |
| F26 缓存引导 | 实现 | QQ 下载后重新检测 |
| F27 缩略图 | 实现 | 内容哈希、LRU、上限可配、清理与损坏重生 |
| F28 合并转发 | 实现并降级 | 本地 XML / NT 文本列表展开；只有服务器引用明确未展开 |
| F29 语音 | 实现 | 时长及原始音频下载，不转码/转写 |
| F30 扩展类型 | 实现 | 文件名、卡片标题、红包/通话与时间；文件先另存后打开 |
| F31 媒体去重 | 实现 | SHA256 内容寻址；不只信任声明 MD5，相同字节独立副本一份 |
| F32 本机媒体重试 | 实现 | 重开只读工作副本并重建全局本机媒体索引；不联网补档 |
| F33 多账号 | 实现 | 多账号无预选，明确选择/切换，generation 隔离 |
| F34 设置持久化 | 实现 | 目录/格式/窗口/上次账号；损坏原字节备份后恢复 |
| F35 密度 | 实现 | 标准默认 / 紧凑，不增加主题分叉 |
| F36 插件 | 按任务书排除 | 不提供任意脚本执行入口 |

当前候选版的性能例外、目标机器与 Windows 10 未验证项目见
[性能验收](P2-performance.md)。这些项目阻止转正式版，不以“功能实现”掩盖。
