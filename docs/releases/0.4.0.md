## 下载与运行

- 安装版：`Qilu-Setup-0.4.0-x64.exe`，运行安装向导，包含卸载程序。
- 便携版：`Qilu-0.4.0-x64.zip`，完整解压后运行 `绮录QQ聊天记录导出软件.exe`。
- 无需安装 Python 或 Node.js。保留主程序旁的 DLL、`locales` 和 `resources`。

## 功能更新

- 新增启动隐私确认：背景虚化，支持本机全文及 GitHub Pages 在线阅读；同意后才读取账号及记录，拒绝或 Esc 退出。
- 敏感个人信息处理单独确认；联网头像独立可选，默认关闭。
- 消息库、联系人、群资料和媒体索引采用四线程并行准备。
- 上线[绮录主页](https://qingzhi-star.github.io/QL-qq-chat-history-exporter/)、[隐私条款](https://qingzhi-star.github.io/QL-qq-chat-history-exporter/privacy.html)，开启[讨论区](https://github.com/qingzhi-star/QL-qq-chat-history-exporter/discussions)。
- 已有本机有效密钥或绮录归档时可离线使用；未取得密钥的历史账号仍无法仅凭加密数据库离线解密。

## 问题修复

- 修复 QQ 写库时切换账号、打开群聊偶发解密报错；快照忙自动重试，失败保留可用聊天。
- 后台刷新不再占用消息读取锁，旧账号的异步结果不会覆盖新账号。
- 随机滚动改用 32 条分页、最多两个在途请求，优先当前位置，丢弃未发送的过期请求；重复读取复用有界缓存。
- 头像网络请求与消息请求分离，断网时不因头像超时阻塞聊天读取。
- 修复隐私条款文件漏打包导致的启动报错，并加入真实 ASAR 文件及哈希检查。
- “更多功能”标题与右上叉号固定，仅下方列表滚动，取消底部关闭按钮。
- 修复账号口令提示更新后造成的 Python CI 断言失败。

已验证 **Windows 11 x64**。Windows 10、其他架构及其他操作系统暂未列入已验证支持范围。
