# 离线归档 v1

右击主界面“导出…”打开更多功能，可创建、打开和校验 `.qqarchive`；CLI `archive create/verify/export`
使用相同实现。离线打开、搜索与导出无需运行 QQ。普通归档是 ZIP：manifest.json
描述账号哈希、会话与格式版本，messages/*.jsonl 保存版本化消息，media/ 保存独立
附件副本，view/*.html 与 index.html 提供普通浏览器兜底，checksums.sha256 覆盖所有
其他成员。解析前检查全部成员与摘要，再核对消息条数、顺序与时间边界。

归档拒绝路径穿越、绝对路径、符号链接、大小写重名及 Windows 保留文件名。
当前限额为 32GiB 解压总量、50000 成员、32MiB 中央目录及单条消息 32MiB；
超过限额应分会话创建多个归档。写入临时文件，成功才原子替换目标；取消保留旧文件。

可选密码加密使用 cryptography 的 AES-256-GCM 和 scrypt（N=32768、r=8、p=1，
256 位密钥）。文件为 8 字节 `QQARC1E\0`、16 字节随机盐、12 字节随机 nonce、
密文及 16 字节 tag；头部参与认证。密码至少 8 字符，只在本次操作内使用，
不保存、不记录，遗忘无法恢复；CLI 用隐藏提示输入，不接受命令行明文密码。
只有通过认证才解包，不提供未经认证的明文。

打开时生成应用 work/archives 下的明文副本，关闭资料且后台工作结束后删除。
崩溃残留在下次启动清理；存活进程目录保留。关闭前的临时明文和用户主动创建的
普通归档一样可能含私密消息。外部打开附件先让用户选择保存位置，不把临时文件
交给可能长期持有它的外部程序。

本机资料库是独立的显式选项，导入前确认长期保存明文；即使归档加密，导入结果
仍为明文。按账号哈希隔离，以会话/时间/消息 ID 合并，完全相同的消息去重，
同标识不同内容整体回滚；不自动覆盖。读视图使用独立快照，避免导入移动选择位置。
更多功能右键菜单提供打开和清空，清空需要确认，跨进程租约阻止删除仍在使用的资料库。
归档原文件及 QQ 数据均保留。资料库不是密钥缓存，也不会自动导入账号数据。
