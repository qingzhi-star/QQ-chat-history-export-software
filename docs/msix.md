# MSIX 分发说明

0.4.0 的 MSIX 使用已验收 Electron 完整目录独立封装，保持原 exe、DLL、资源、
绮录名称和图标。没有重新编译或替换主发行目录中的文件。

- 包身份：`qingzhi-star.Qilu.Desktop`；版本 `0.4.0.0`；架构 x64。
- 最低系统：Windows 11（`10.0.22000.0`），FullTrust 桌面应用。
- 工具：微软 Windows SDK BuildTools 10.0.26100.9457 的 MakeAppx；工具签名验证有效。
- 校验：1113 个原载荷逐文件 SHA-256、ZIP CRC、7628 个 BlockMap 块、125 个整文件哈希及 Manifest 均通过，原发行目录未变。

当前文件为**未签名 MSIX**，不属于已安装/运行验收的正式安装渠道。普通 Windows
安装需要适当的受信任签名；没有安装证书、更改系统信任或侧载设置。安装版 exe 和
便携 ZIP 仍为本轮已验收渠道。MSIX 未混入正式 Release 的两个既定资产。

包管理器负责 MSIX 的安装和卸载，包内无需额外塞入 Inno 卸载器。
后续正式分发应由维护者提供合适的签名身份，并补做安装、启动、升级与卸载验收；
不能把“包结构验证通过”写成“Windows 安装及运行验证通过”。
