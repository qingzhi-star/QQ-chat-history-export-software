# 界面以 0.1.0 原源码为准

用户于 2026-11-06 明确要求：UI 与 0.1.0 保持一致，不重新设计，只优化内核。
这条约束优先于此前 P2 关于新预览样式和菜单栏的实施决定。

直接读取的基准为标签 `v0.1.0-pre.2`，提交
`37e6a9935e8ba649103357f1fc39cf19bd6d82e7` 的 `qqexport/gui.py`：

```powershell
git show v0.1.0-pre.2:qqexport/gui.py
```

0.2.0rc2 恢复时，`gui.App` 下列函数与该源码作 AST 对比，函数逻辑完全未变；
后续按用户要求修订的部分在本文末尾单列：

- `_build`：双栏、会话列表、标题、导出/全选/日期/下一步/取消的位置。
- `_append_message`、`_insert_segments`：日期、绿色己方气泡、引用、撤回、表情和图片。
- `_build_selection_rows`、`_draw_check`、`_row_text`：原版多选控件、灰色圆圈和整行淡蓝底。
- `_avatar_photo`：原版圆形头像裁剪与尺寸。

`classic_row.py` 只适配分页索引与异步图片回填：普通消息直接调用上述原绘制函数，
多选控件直接由原 `_build_selection_rows` 创建，未另写多选布局或气泡样式。
`virtual_list.py` 继续维持有界可视控件池和页面缓存；行高缓存只减少重复测量，
不改变字体、内容、颜色或原始源码的绘制方式。主窗格请求尺寸沿用原 Text 控件，
避免替换内部容器后双栏比例漂移。旧版上边距及右边距同样保留。

P2 新功能收进右击导出按钮、标题、预览空白的更多功能菜单；消息右键可进入同一菜单。
主窗口不增加菜单栏、工具栏或按钮。Ctrl+F 搜索，Ctrl+Shift+E 批量。
单会话导出使用现有安全导出引擎，恢复原完成提示；批量队列仅在明确打开批量功能时显示。

验收使用同一组合成消息对照旧源码：普通/多选、自己/他人、两张图片、引用、撤回和跨日。
回归还检查末尾正文未裁切、完整两张缩略图、进入/退出选择的锚点、日期范围、搜索跳转、
单会话不出现队列窗口，以及十万行控件与页面上限。没有用真实聊天截图作版本库基准。

后续修改不得以性能或架构调整为由重新设计 UI。需要改变外观时，先有用户明确新要求。

0.2.0rc3 用户追加要求：显示圆角头像、文件显示 `[文件] 文件名`，图片交给系统默认
查看器。因此在保留上述布局/绘制流程的基础上，明确修改头像裁剪和文件段这两处旧函数；
不再声称这两处仍与旧标签逐字一致。恢复原版 QQ 头像获取入口，独立后台池返回到主线程，
切换账号丢弃旧结果，界面与公共头像内存缓存均有界；归档/合成测试不请求头像。
图片使用独立缓存副本和正确扩展名调用系统关联，关闭归档或导出器不提前删除查看器文件。

0.2.0rc4 修复底部判断使用百分比导致大列表向上滚动后被拉回底部的问题，改按实际
剩余像素判断。异步图片/页回填在绘制期间继续安排刷新；首次宽度变化重新测量行高，
行高收缩时约束锚点偏移。普通/多选均有十万行真实滚轮事件回归。
回复解析补充本地 47713 摘要布局并保留嵌套全部元素；没有保存引用正文时明确显示
“引用正文未保存在本机”，普通预览、多选与导出都不再空白或只剩 `[回复]`。
多选仍由旧 `_build_selection_rows` 创建原版控件，同结构消息更新控件内容；有界控件池
优先复用同内容结构，头像/缩略图共享有界 Tk 图片缓存，减少反复重建。回归检查复用后
发件人/正文/图片引用与选择底色正确。仅修复 `_insert_segments` 和 `_row_text` 的回复
投影，不再将这两处称为与旧版完全相同；其他布局/颜色不变。

0.2.0rc5：修复左侧会话列表不足一屏时，继续向上滚动会将内容推离顶部的问题。
滚动区域至少覆盖当前视口，内容和窗口尺寸变化时同步；滚轮到达上下边界后停止并
消费事件。仅调整 `_build` 中两处滚动几何回调和 `_wheel` 的边界处理，保持旧版布局。

0.2.0rc6：用户明确要求在窗口最左下角添加账号按钮。`ProductApp._build` 在会话计数
下方追加“选择/切换账号…”按钮，复用现有账号发现和选择流程；其余布局不变。
成功切换清空旧会话预览/标题、导出勾选和批量选择，取消保留当前会话；账号列表不默认
选择第一个，仅标记上次账号。旧版不新增按钮的约束在此按用户要求增加这一处例外。

0.2.0rc7：用户要求账号切换点击即用。账号选择后由后台自动验证缓存、按需只读扫描
所选账号口令并 DPAPI 保存，再加载会话；无需用户运行命令。选择弹窗说明自动加载，
处理期间暂禁重复点击，失败显示具体原因并保留当前会话。主窗口布局不再增加控件。
