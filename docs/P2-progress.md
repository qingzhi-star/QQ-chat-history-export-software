T01：普通测试 565 通过，10 live 排除；默认与全库隐私巡检通过。
`tools/bench_product.py --messages 100000` 使用合成 SQLite；定位表只存键，正文
最多每页 1000 条（默认 128）解析，稳定游标含 rowid 解决相同时间/ID 的定位。
只读源文件字节哈希在分页前后相同。193.2ms 是 Repository 首屏页，不等同 GUI
首屏；2.49MiB 是 tracemalloc 的 Python 分配峰值，不含 SQLite C 堆/RSS，留待 T10。

T04：普通测试 586 通过，10 live 排除；隐私巡检通过。左侧 Ctrl 多选和独立批量

恢复前校验账号及已完成文件哈希，损坏或冲突停止且不覆盖原状态。

T05：普通测试 595 通过，10 live 排除；隐私巡检通过。显式开启整会话增量才保存
`messages.jsonl`、独立媒体及版本化 manifest。TXT 保留旧字节并追加，HTML 流式复制
旧消息区、更新页头并追加，PDF 从完整更新 HTML 重生。无新增不改产物时间戳。

T07：普通测试 610 通过，10 live 排除。清单按当前会话列出位置、ID、时间、类型，
