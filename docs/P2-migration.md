# 升级到 0.2.0rc1

这是 P2 功能候选版。每个任务分别提交，直到发布收尾才从 0.1.1rc1 升为 0.2.0rc1；
任务数不影响版本号。完整规则见 [VERSIONING.md](VERSIONING.md)。P1+ 修复已包含在
P2 源码；未把缺少正式版验收的 0.1.1rc1 另标成稳定的 0.1.1。

升级前关闭正在导出的旧实例，保留原导出目录和配置备份。源 QQ 数据不会迁移或修改。
绿色版整体替换 EXE 与 `_internal`；不可混用不同版本运行库。安装包按当前用户覆盖
应用文件，不删除用户创建的归档/备份。降级时请使用独立目录并备份本机配置。

| 数据 | 新版处理 | 降级 / 故障处理 |
|---|---|---|
| 旧 config.json | 缺少新字段使用默认；类型错误保留原文件，本次不保存 | 显式恢复先生成原字节 `.bak-随机标识`；不要手工删除唯一备份 |
| 密钥缓存 | 保留已有 DPAPI 格式，不自动重新扫描进程 | 仅原 Windows 用户可解密；迁移账号需本人重新设置 |
| 普通 TXT/HTML/PDF | 可继续阅读，不自动推断增量游标 | 另目录重导；选择覆盖时原子替换整会话目录 |
| 增量备份 v1 | 验证账号、格式、旧文件、快照条数和首尾，再追加 | 旧目录无清单/版本冲突/损坏时停止，显式全量重建，保留 previous-manifest.json |
| `.qqarchive` v1 | 校验完整性后只读挂载；加密需密码 | 未知版本拒绝，保留原文件；普通 ZIP 可解包用 HTML 兜底 |
| 资料库 SQLite v1 | 原型版本 0 的同结构表可登记为 user_version=1 | 未来版本拒绝，原文件保留；不自动跨未知模式改写 |
| 恢复队列 | 仅任务参数/状态，打开时校验账号与已完成文件 | 旧参数用默认；坏检查点拒绝，不静默覆盖 |
| 搜索索引 | 默认内存，随资料关闭销毁 | 无持久正文索引迁移；首次搜索重新建立 |
| 搜索历史 | 用户显式启用才存本机 | 搜索窗口可清除；关键词可能含敏感内容 |
| 缩略图 | cache/thumbs 中内容哈希 PNG，默认 2GiB | 可全部清空重新生成；不影响 QQ 原图 |
| 计划导出 | XML + JSON 默认禁用，用户自行核对导入启用 | 移动软件/源码解释器后重新生成并在系统任务计划程序停用旧任务 |

资料库、增量快照、普通归档、导出正文和缩略图均可能包含明文内容。资料库清空只操作
应用专有目录且使用跨进程租约；归档关闭后释放临时明文，崩溃目录在下次启动按 PID
清理。保留运行中的工作目录，不把缓存清理解释为原 QQ 内容恢复或删除。

媒体快照 v1 允许相对文件名变化，内容引用以 JSONL 为准；新版统一 SHA256 `.bin`
寻址，原始名称仍在元数据中。TXT 的文件名、语音时长与缺失说明比旧版更完整，
增量模式不会自动重写历史正文。需要逐条核对历史中部变化时，请另目录全量重建。
